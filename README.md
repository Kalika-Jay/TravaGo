🌍 TravaGo – Discover Sri Lanka Together
TravaGo is a web-based travel companion platform built specifically for Sri Lanka. It connects like-minded travelers, promotes off-the-beaten-path exploration, and simplifies trip planning through intelligent recommendations and interactive tools.

🚀 Features
Traveler Matching System based on user profiles, interests, and travel preferences

Trip Discovery with advanced filters, trending destinations, and machine learning suggestions

Interactive District Map with detailed travel info layers (routes, accommodations, POIs)

Trip Feed for publishing and discovering travel plans

Real-time Communication with group chats and trip announcements

Post-trip Feedback System with reviews, ratings, and moderation

🛠 Tech Stack
Frontend: React.js, CSS

Backend: Node.js, Express.js

Database: MongoDB

ML Engine: Python, scikit-learn, pandas, NumPy

🔍 Unique Value
Designed specifically for Sri Lanka, including lesser-known destinations

Supports all traveler budgets from backpackers to luxury

Fosters community and safety with verified user profiles and trip reviews

🎯 Target Audience
Solo travelers seeking companions

Groups wanting to expand their travel circle

Anyone exploring Sri Lanka in a more social and authentic way
